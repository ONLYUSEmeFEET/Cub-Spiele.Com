HARDWARE, ARCHITECTURE & EMULATION REFERENCES
---------------------------------------------
- Sharp Corporation
  * Sharp SM8521 8/16-Bit Single-Chip Microcomputer Datasheet & Instruction Set
    Manual (CPU Core, ALU Flags, MMU $0010-$0013, DMA Blitter $0020-$002D,
    SGDA $004E 8-bit DAC, SG0/SG1/SG2 Tone Generators, and Interrupt Controller).

- Tiger Electronics, Inc. (1997)
  * Original Tiger Game.Com Handheld Console Hardware Architecture, 4KB Internal
    ROM ($2000-$2FFF), 32KB External Kernel ROM, Dual Cartridge Bus Isolation
    (Port 3 Bit 6), 13x10 Resistive Touch Matrix, and $FC60-$FEDF Battery-Backed
    NVRAM High Score Table format.

- MAME (Multiple Arcade Machine Emulator) Project — Game.Com Driver (`gamecom.cpp` / `sm8500`)
  * https://github.com/mamedev/mame
  * Historical hardware register map and SM8500/SM8521 instruction set reference
    (Wilbert Pol, Robbbert, and the MAMEdev team).

- mGBA & melonDS Projects
  * https://mgba.io/ | https://melonds.kuribo64.net/
  * Desktop UI/UX design inspiration for standalone handheld emulator menu bar
    (`File`, `Emulation`, `Audio/Video`, `View`, `Tools`), Screen-Only integer
    scaling (`2x`/`3x`/`4x`), and multi-window link cable ergonomics.


COMPETITIVE ECOSYSTEM & LEADERBOARD INTEGRATIONS
------------------------------------------------
- RetroAchievements (`rcheevos` & `dorequest.php` Connect API)
  * https://retroachievements.org/
  * https://github.com/RetroAchievements/rcheevos
  * https://github.com/RetroAchievements/RAIntegration
  * Competitive Hardcore Mode specification (save-state lock, sub-1.0x slowdown
    prohibition, cold-boot session verification, debugger step protection),
    `rcheevos` memory condition syntax, Rich Presence script evaluation, and
    `rc_consoles.h` 32KB flat SM8521 memory map specification.

- RFC 1321 (MD5 Message-Digest Algorithm) & FNV-1a (Fowler-Noll-Vo Hash)
  * Used for deterministic ROM cartridge identification and rolling hardware
    input entropy attestation in `CSC1-...` Signed Score Certificates.
